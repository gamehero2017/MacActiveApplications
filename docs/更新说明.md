# 更新说明

> 文档日期：2026-08-04  
> 相对上一版 README 所描述的功能基线，汇总近期产品与实现变更。

## 概述

本轮更新强化了任务栏作为日常启动器的完整度：固定 **Apps（原启动板）** 入口、完善 **悬停标题栏** 与 **右键菜单**，并提供本工具自身的退出方式；同步修订 README 与项目结构说明。

---

## 新增功能

### 1. Apps / 启动板固定入口

- 位置：列表最左侧区域中，排在 **访达之后**
- 仅显示系统图标，无文字标签
- 单击：切换 Apps / 启动板开合，行为对齐 Dock（`CoreDockSendNotification` → `com.apple.launchpad.toggle`）
- 折叠任务栏时：只保留把手，不露出 Apps 图标
- **无右键菜单**、无悬停窗口列表
- 系统适配：优先 `/System/Applications/Apps.app`（如 macOS 26+），否则回退 `Launchpad.app`

相关文件：`Model/SystemAppsLauncher.swift`、`RunningAppsStore.swift`

### 2. 悬停标题栏：单窗口也显示

- 原逻辑：仅当窗口数 ≥ 2 时弹出
- 现逻辑：只要存在可见窗口（含 1 个）即弹出标题栏列表
- 无可见窗口时仍不弹出

相关文件：`Panel/WindowPeekController.swift`

### 3. 应用图标右键菜单

| 类型 | 菜单项 |
|------|--------|
| 通用 | 显示、隐藏、在访达中显示、退出 |
| 访达额外 | 新建访达窗口 |
| Apps | 无右键 |

实现要点：在 accessory / 非激活面板上使用 AppKit 透明命中层 + `NSMenu.popUp`，避免 SwiftUI `contextMenu` 收不到右键的问题。

相关文件：`Model/AppContextMenuBuilder.swift`、`UI/TaskbarView.swift`、`RunningAppsStore.swift`

### 4. 把手右键「退出任务栏」

- 本工具无 Dock 图标，新增把手右键 → **退出任务栏**（`NSApp.terminate`）
- 仍可用终端 `Ctrl+C` 或 `killall MacActiveApplications` 退出

相关文件：`UI/TaskbarView.swift`

### 5. 列表排序调整

- 访达固定最左
- Apps 固定紧随访达
- 其余运行中应用仍按本地化名称排序

## 行为与实现说明（补充）

| 主题 | 说明 |
|------|------|
| 运行中应用来源 | `NSWorkspace.runningApplications`（非遍历 Dock UI） |
| Apps 切换原理 | 不能用普通 `DistributedNotificationCenter`；需 HIServices `CoreDockSendNotification` |
| 图标交互 | 左键 / 右键 / 悬停由透明 `NSView` 命中层统一处理 |
