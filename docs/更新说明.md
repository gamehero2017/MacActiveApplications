# 更新说明

> 文档日期：2026-08-06
> 当前版本：`2.5.1`（`Resources/Info.plist`）
> 覆盖自 Apps / 右键菜单基线以来的产品与实现变更。

## 概述

在 Apps 固定入口、悬停 Peek、应用右键菜单与汉堡设置之上，近版增加了**图标拖拽排序并持久化**、**显示访达开关**、以及基于 Dock `AXStatusLabel` 的**未读红点 / 来消息跳动**（可关停轮询；休眠与锁屏时暂停）。此前还补齐了本地化、显示桌面错位修复、打包跨机崩溃修复等。

## 2026-08-06 · v2.5.1

### 1. 图标拖拽排序

- 按住任务栏图标拖动可调整顺序；松手后写入 `UserDefaults`（按 `bundleIdentifier`）
- 重启任务栏或应用再次出现时恢复上次位置；新应用排在末尾
- 拖拽时图标浮层跟随光标，光标为抓取小手；轻点仍为激活 / 隐藏

相关文件：`RunningAppsStore.swift`、`TaskbarPreferences.swift`、`UI/TaskbarView.swift`

### 2. 显示访达

- 汉堡菜单新增「显示访达」勾选（默认开）；关闭后任务栏不显示访达图标

相关文件：`TaskbarPreferences.swift`、`TaskbarSettingsMenuBuilder.swift`、`RunningAppsStore.swift`

### 3. 未读红点与来消息跳动

- 经辅助功能读取 Dock 图标 `AXStatusLabel`；有角标时任务栏只显示红点（不显示数字）
- 角标出现或数字变化时，图标向上连弹数下（类 Dock 提醒）
- 汉堡菜单「显示未读红点」：关闭后**彻底停止**轮询与绘制
- 系统休眠 / 显示器休眠 / 锁屏时暂停轮询，唤醒 / 解锁后恢复（保留红点状态）
- 轮询间隔约 1s，带较大 `tolerance`，未授权辅助功能时不弹窗、不深挖 AX

相关文件：`Model/DockBadgeMonitor.swift`、`RunningAppsStore.swift`、`UI/TaskbarView.swift`

## 2026-08-05 · v2.2.4

### 其它机型安装后启动即退出

- 现象：DMG 装到另一台 Mac（如 13 寸）后进程立刻消失，无法使用
- 日志：`could not load resource bundle: … MacActiveApplications_MacActiveApplications.bundle`
- 原因：`L10n` 使用 SPM `Bundle.module`，只查找 `.app` 根目录与**编译机** `.build` 路径；打包却把资源放在 `Contents/MacOS/`，其它机器两边都找不到 → `fatalError`
- 处理：
  - 自行解析资源包（`Contents/MacOS` / `Contents/Resources` / 可执行文件旁）
  - 打包脚本同步拷贝到 `Contents/MacOS` 与 `Contents/Resources`
  - 找不到资源时不再崩溃

相关文件：`L10n.swift`、`scripts/package-dmg.sh`

## 2026-08-05 · v2.2.3

### 1. 汉堡菜单：点击旋转为 X

- 打开设置菜单时，三条横线以弹簧动画旋转成 **X**
- 菜单关闭后动画转回汉堡图标

相关文件：`UI/TaskbarView.swift`（`HamburgerToXIcon`）

### 2. 辅助功能授权不再反复弹窗

- 现象：未授权时启动、悬停 Peek 等路径反复弹出系统授权框，影响使用
- 处理：
  - 自动弹窗：**整个安装生命周期最多一次**（`UserDefaults` 记录）
  - Peek / 窗口操作 / Apps AX 回退：**不再弹窗**；未授权则功能降级
  - 之后如需授权：汉堡菜单 →「辅助功能」→ 打开系统设置

相关文件：`Model/AppWindowService.swift`、`AppDelegate.swift`、`Panel/WindowPeekController.swift`、`SystemAppsLauncher.swift`

## 2026-08-05 · v2.2.2

### 触发角「显示桌面」后把手异常

- 现象：用触发角显示桌面后，操作把手展开/收起显示异常、不能正常收拢或展开
- 原因：Exposé / 显示桌面会挪动未标记 `stationary` 的窗口，随后 `animator().setFrame` 从临时几何插值，导致 frame 与内容错位
- 处理：
  - 任务栏与 Peek 面板增加 `.stationary`
  - 展开/收起改为瞬时落地，并清除残留动画后强制对齐 frame

相关文件：`Panel/MenuBarPanel.swift`、`Panel/WindowPeekController.swift`

## 2026-08-05 · v2.2.1 及同日此前变更

### 1. 汉堡设置菜单（最左侧）

- 展开时最左侧显示三条横线；**收起后只留把手**（汉堡一并隐藏）
- 向下展开 `NSMenu`，项目包括：
  - 版本信息（不可点）
  - 辅助功能状态（点击打开系统设置）
  - 显示 Apps（勾选；关闭后任务栏不显示 Apps 入口）
  - 悬停显示窗口列表（勾选；关掉 Peek）
  - 记住展开/收起状态（勾选；关闭则每次启动默认展开）
  - 开机启动（勾选；需以 `.app` 运行才稳定生效）
  - 退出任务栏
- **把手**：仅左键收起/展开；右键「退出任务栏」已移除

相关文件：`TaskbarPreferences.swift`、`TaskbarSettingsMenuBuilder.swift`、`UI/TaskbarView.swift`、`UI/TaskbarStyle.swift`

### 2. Apps 开合后无法输入（焦点）

- 现象：打开再关闭 Apps 后，桌面其它应用有时无法输入
- 原因：任务栏 `NSPanel` 抢占 key window，焦点未还给原应用
- 处理：面板默认不可成为 key（仅弹菜单时临时允许）；Apps 切换前后让出焦点，关闭后恢复先前前台应用

相关文件：`Panel/MenuBarPanel.swift`（`TaskbarFocus`）、`SystemAppsLauncher.swift`、`RunningAppsStore.swift`

### 3. 多语言（跟随系统语言）

- 不做应用内切换语言；跟随 macOS 系统语言
- 当前：`en` / `zh-Hans`（`Localizable.strings`）
- 统一入口：`L10n.swift`（规避 SwiftPM 将 `zh-Hans.lproj` 拷成 `zh-hans` 导致匹配失败回退英文的问题）
- 打包脚本会把 SPM 资源包拷入 `.app`（`Contents/MacOS/*.bundle`）
- DMG 文件名版本号改为读取 `Info.plist` 的 `CFBundleShortVersionString`

相关文件：`L10n.swift`、`Resources/en.lproj`、`Resources/zh-Hans.lproj`、`Package.swift`、`scripts/package-dmg.sh`

## 2026-08-04（基线回顾）

### Apps / 启动板固定入口

- 访达之后固定入口；单击切换开合（`CoreDockSendNotification` → `com.apple.launchpad.toggle`）
- 无右键、无 Peek；折叠时不露出 Apps

### 悬停标题栏（Peek）

- 有可见窗口即弹出（含单窗口）；可聚焦 / 最小 / 最大 / 关闭

### 应用图标右键

| 类型 | 菜单项 |
|------|--------|
| 通用 | 显示、隐藏、在访达中显示、退出 |
| 访达额外 | 新建访达窗口 |
| Apps | 无右键 |

### 列表排序

默认：访达 → Apps → 其它运行中应用（按名称）。用户拖拽后按 `bundleIdentifier` 持久化顺序。

## 行为与实现说明（补充）

| 主题 | 说明 |
|------|------|
| 运行中应用来源 | `NSWorkspace.runningApplications`（非遍历 Dock UI） |
| Apps 切换原理 | HIServices `CoreDockSendNotification`；符号失败时才 AX 点 Dock |
| 图标交互 | 左键 / 右键 / 悬停 / 拖拽由透明 `NSView` 命中层处理 |
| 图标顺序 | 可拖拽；`UserDefaults` 按 `bundleIdentifier` 持久化 |
| 未读红点 | Dock `AXStatusLabel` 轮询；关偏好则停表；休眠/锁屏暂停 |
| 界面语言 | 跟随系统；自研资源包查找 + 手动匹配 `.lproj` |
| 显示桌面 | 面板使用 `.stationary`，避免被 Exposé 挪走 |
| 辅助功能弹窗 | 自动弹窗最多一次；之后仅汉堡菜单可打开设置 |
